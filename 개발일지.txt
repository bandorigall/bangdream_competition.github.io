갤대회 — 개발일지

(레포: bandorigall/bangdream_competition.github.io / GitHub Pages)

■ 배경/동기
  방갤에서 유저 주최 갤 대회가 수시로 열리는데, 갤 글로만 흩어져 있어
  "지금 뭐가 진행 중이고 언제 끝나는지" 한눈에 보기 어려웠다.
  이걸 카드형 대시보드로 모아 마감 임박순으로 보여주자는 게 시작.
  덤으로 "지금 진행 중인 대회의 주최자 식별코드"를 뽑아두면
  다른 도구에서 재활용할 수 있어 klolman_list 산출을 함께 넣었다.

■ 구조 확정
  - 데이터는 events.csv 한 곳에서만 관리(제목/주최자/식별코드/시작·종료일/링크).
  - main.py 가 CSV를 읽어 index.html(정적)과 klolman_list.py(JSON)를 생성.
  - 정적 페이지라 서버가 필요 없고, GitHub Pages로 그냥 배포.

■ 주요 결정 및 이유
  - 종료일에 시각이 없으면 23:59:59로 보정 → "마지막 날 하루 종일 진행 중"
    으로 자연스럽게 취급하기 위함. (자정 처리 안 하면 종료일 00:00에 끝나버림)
  - 카드 상태 색: 3일/7일/30일 임계로 critical/warning/notice/safe 구분,
    3일 미만은 pulse 애니메이션으로 시선 유도.
  - 마감 임박순 정렬에서 이미 끝난 대회는 큰 수로 밀어 목록 뒤로.
  - klolman_list.py 를 .py 확장자로 둔 건 외부 파이썬 import 편의(내용은 JSON).

■ 이력(커밋 흐름 요약)
  - 초기: 잦은 "Auto commit"(git_auto.sh 자동 커밋)으로 데이터/레이아웃 갱신 반복.
  - 중간: JSON 직렬화 시 Timestamp 컬럼 때문에 터지던 이슈를
    parsed_* 컬럼 drop 으로 해결(코드 주석 "★★★ 핵심 수정").
  - 최근(2026-07): 대회 데이터 갱신.
  - 마지막: 전 사이트 공통 상단 네비게이션 바(nav.js) 추가.
  - 2026-08-21: 모카 생일 기념 대회 2건 추가 (모카그림대회 6428284 / 모카 백일장 6428476).
    백일장 본문에 "종료 09.03 23:59"와 "마지막 편은 09.04 09시까지"가 병존 → 대회 기간 표기(09-03 23:59)를 채택.
  - 2026-08-18 19:18: 다음내한예측대회 종료일을 2026-12-31(임시) → 2026-08-08 로 확정.
    근거는 김치쿠라 개최일. 이미 지난 날짜라 목록에서 종료 처리됨. (커밋 f381752)

■ 운영 메모
  - 대회 추가/수정: events.csv 한 줄 편집 → git_auto.sh 실행이면 끝.
  - now 판정(빌드시 파이썬)과 표시(열람시 JS)가 서로 다른 로컬시계를 쓰므로
    분 단위 경계는 오차가 있을 수 있음. 실용상 문제 없음.
